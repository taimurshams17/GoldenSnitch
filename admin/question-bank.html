Question-specific multimedia

Use structured JSON only. Do not paste HTML, embed code, scripts or arbitrary SVG. Question media accepts static image or diagram only (never simulation, animation or video inside the question). Explanation resources may use image, animation, video, resource, link or diagram. Interactive simulations remain in the separate Lab section. Every external item needs an HTTPS URL. Add rightsStatus (owned / open-license / permission / public-domain / link-only / pending), attribution and license/licenseUrl where applicable; add transcriptUrl for video when available. Question-support media remains unverified until a qualified reviewer checks both relevance and rights.

YouTube videos are displayed through the privacy-enhanced youtube-nocookie player. Simulation and textbook links open in a new tab. HTML-based embeds are rejected by the API.

Academic review & controlled publishing

Only a suitably qualified Physics, Chemistry or Mathematics reviewer should complete this section after checking the exact item. Publishing is a separate action; saving a draft never makes it public.
